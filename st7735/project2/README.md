# PC 画面のミラー表示

PC の画面を縮小して USB で Raspberry Pi Pico W に送り、1.8 インチの ST7735 液晶に表示する。液晶は横向き（160×128 ピクセル）で使う。PC の画面の縦横比を保つため、上下に黒い帯が入る。

## 準備

初めての場合は、先に次の 3 つを済ませる。

1. [Pico W の準備](../../README.md#pico-w-の準備)：Thonny のインストールと MicroPython の書き込み
2. [ST7735 の配線](../README.md#配線)。配線が正しいかは [project1](../project1/) の表示デモで確かめられる
3. PC に [uv](https://docs.astral.sh/uv/) をインストールする

## ファイル構成

```
project2/
├── README.md
├── pico/
│   └── screen_rx.py   # Pico W 側：受信して表示する（Pico W には main.py として保存）
└── pc/
    └── screen_tx.py   # PC 側：画面を撮って送信する
```

## 使い方

### 初回だけ：Pico W に受信側を保存する

1. Pico W を USB で PC につなぎ、Thonny を開く。
2. Thonny の右下で「MicroPython (Raspberry Pi Pico)」を選ぶ。
3. `pico/screen_rx.py` を開き、「ファイル」→「名前を付けて保存」で「Raspberry Pi Pico」を選び、`main.py` という名前で保存する。

### 毎回：画面を映す

1. Thonny を閉じる。Thonny が USB の接続を使ったままだと、PC 側のスクリプトがつながらない。
2. Pico W の USB ケーブルを抜いて挿し直す。液晶が真っ黒になれば、受信を待っている状態である。
3. PC 側のスクリプトを実行する。

   ```
   cd pc
   uv run screen_tx.py
   ```

   初回は、uv が必要なライブラリ（mss、pillow、pyserial、numpy）を自動でインストールする。Pico W の接続先は自動で探す。
4. 止めるときは、ターミナルで Ctrl+C を押す。

### Thonny に戻るとき

Thonny を開けば、Pico W 側の受信は止まる。液晶が固まったまま Thonny がつながらない場合は、USB を挿し直してから Thonny を開く。

`main.py` は Pico W に残るため、電源を入れるたびに受信待ちになる。別のプログラムを自動で動かしたい場合は、`main.py` を上書きする。

## 仕組み

PC と Pico W は、1 コマごとに次の手順でやり取りする。

1. PC が `F` を 1 バイト送る。
2. Pico W は Ctrl-C の検出を止めてから `K` を返す。画像データに 0x03（Ctrl-C と同じ値）が含まれても、プログラムが止まらないようにするためである。
3. PC が 1 コマ分のデータを送る。160×128 ピクセルを RGB565（1 ピクセルを 16 ビットで表す形式）のビッグエンディアンで並べた 40,960 バイトである。
4. Pico W は受信を終えると Ctrl-C の検出を元に戻し、液晶に描く。

Ctrl-C が効くのは、Pico W が `F` を待っている間だけである。そのため、Thonny の停止ボタンや Thonny の接続で止められる。

## 注意

- 何も映らない場合は、配線が原因のことが多い。「[表示されないとき](../README.md#表示されないとき)」を見る。
- macOS では、初回にターミナルへ「画面収録」の許可を与える必要がある。許可しないと、壁紙しか映らない。
- 上下が逆さに映る場合は、`screen_rx.py` の `b"\xA0"` を `b"\x60"` に変える。
- PC の画面を幅 160 ピクセルまで縮めるため、文字はほとんど読めない。
- 1 コマの受信の途中で PC 側が止まると、Pico W は固まる。USB を挿し直せば戻る。
- 1 秒あたりのコマ数は計測していない。液晶への転送だけで 1 コマあたり約 26 ms かかり、これに USB での受信時間が加わる。
